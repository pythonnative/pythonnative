# Video

[`Video`][pythonnative.video.Video] plays local and remote video in a native
player view, and a `ref` on it publishes a
[`VideoHandle`][pythonnative.video.VideoHandle]. Enable it with `use = ["video"]`
under `[plugins]`. See the [Video guide](../guides/capabilities/video.md).

    options:
      show_root_heading: false
      show_root_toc_entry: false
      members_order: source
