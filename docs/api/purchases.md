# Purchases

[`Purchases`][pythonnative.purchases.Purchases] sells in-app products through StoreKit 2
and Google Play Billing, and [`fake_store`][pythonnative.purchases.fake_store] stands in
for both off device. Enable it with `use = ["purchases"]` under `[plugins]`. See the
[Purchases guide](../guides/capabilities/purchases.md).
