# Background

[`background.task`][pythonnative.background.task] declares Python that runs while the
app isn't open, and [`background.schedule`][pythonnative.background.schedule] asks the
system to run it. Enable it with `use = ["background"]` under `[plugins]`. See the
[Background guide](../guides/capabilities/background.md).
