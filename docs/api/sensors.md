# Sensors

[`Accelerometer`][pythonnative.sensors.Accelerometer],
[`Gyroscope`][pythonnative.sensors.Gyroscope],
[`Magnetometer`][pythonnative.sensors.Magnetometer], and
[`Barometer`][pythonnative.sensors.Barometer] stream readings as async
iterators, in the same units and axes on every platform. See the
[Sensors guide](../guides/capabilities/sensors.md) for setup and platform
differences.
