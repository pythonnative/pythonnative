# Notifications

[`Notifications`][pythonnative.notifications.Notifications] schedules local
notifications and reports when they arrive or get tapped. Enable it with
`use = ["notifications"]` under `[plugins]` and `notifications = true` under
`[permissions]`. See the [Notifications guide](../guides/capabilities/notifications.md).
