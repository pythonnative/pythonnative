# DevTools agent and error reports

The in-app half of [PythonNative Go and DevTools](../guides/devtools.md):
the agent that answers DevTools, the inspector it uses, the REPL, live
performance sampling, and the debugger integration. Development builds
only; release bundles omit `pythonnative.devtools`.
