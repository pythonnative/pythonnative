# Audio

[`Sound`][pythonnative.audio.Sound] plays audio,
[`Recorder`][pythonnative.audio.Recorder] records it, and
[`Audio.set_mode`][pythonnative.audio.Audio.set_mode] sets how the app's audio
relates to the device and other apps. Enable it with `use = ["audio"]` under
`[plugins]`. See the [Audio guide](../guides/capabilities/audio.md).
