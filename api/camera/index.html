    Camera¶

    The camera capability shows the system camera screen or a live preview you control. See the Camera guide for setup and platform differences.

    The device camera: the system capture screen, or a live preview you control.

    Enable it in pythonnative.toml. Declare microphone as well if you record video with sound:

    [plugins]
use = ["camera"]

[permissions]
camera = "Scan receipts with your camera."
microphone = "Record sound with your videos."
    Example 
    import pythonnative as pn
from pythonnative.camera import Barcode, Camera, CameraView

async def snap() -> None:
    path = await Camera.take_photo(quality=0.8)
    if path is not None:
        await upload(path)

@pn.component
def Scanner() -> pn.Node:
    camera = pn.use_ref()

    async def capture() -> None:
        photo = await camera.current.take_picture(quality=0.8)
        print(photo.path, photo.width, photo.height)

    def scanned(barcode: Barcode) -> None:
        print(barcode.type, barcode.data)

    return pn.Column(
        CameraView(
            ref=camera,
            barcode_types=["qr", "ean13"],
            on_barcode=scanned,
            style=pn.style(flex=1),
        ),
        pn.Button("Capture", on_press=capture),
    )

    CameraView ¶

    CameraView(
    *children: Node,
    facing: CameraFacing = "back",
    flash: CameraFlash = "off",
    zoom: float = 1.0,
    barcode_types: Optional[Sequence[BarcodeType]] = None,
    on_barcode: Optional[Callable[[Barcode], Any]] = None,
    on_ready: Optional[Callable[[], Any]] = None,
    on_error: Optional[Callable[[CameraError], Any]] = None,
    accessibility_label: Optional[str] = None,
    test_id: Optional[str] = None,
    style: StyleProp = None,
    ref: Optional[Ref] = None,
    key: Optional[str] = None
) -> Element

    Show a live camera preview: AVFoundation on iOS, CameraX on Android.

    A preview has no intrinsic size, so give it one with style, such as pn.style(flex=1) or pn.style(height=240). Passing a ref publishes a CameraViewHandle on ref.current.

    It prompts for the camera permission when it first appears. It never raises for a missing camera or a refused prompt: it shows a placeholder and calls on_error, which is what happens on the iOS simulator. Android runs one preview at a time, so the CameraView shown most recently wins.

    Parameters:

    Name Type Description Default
    *children Node

    Elements to draw on top of the preview, such as a scan frame.

    		 ()
    facing CameraFacing

    The lens to use.

    		 'back'
    flash CameraFlash

    The flash mode. A device without a flash ignores it.

    		 'off'
    zoom float

    Magnification, where 1 is none. It's clamped to what the current lens supports.

    		 1.0
    barcode_types Optional[Sequence[BarcodeType]]

    The symbologies to look for. Scanning runs only when this isn't empty, and costs nothing otherwise.

    		 None
    on_barcode Optional[Callable[[Barcode], Any]]

    Called with a Barcode when one comes into view, and for the same text again only after it has been out of view for a moment.

    		 None
    on_ready Optional[Callable[[], Any]]

    Called each time the preview starts.

    		 None
    on_error Optional[Callable[[CameraError], Any]]

    Called with a CameraError when the camera can't run.

    		 None
    accessibility_label Optional[str]

    Screen reader label for the preview.

    		 None
    test_id Optional[str]

    Identifier for UI tests.

    		 None
    style StyleProp

    Layout and visual style.

    		 None
    ref Optional[Ref]

    Optional Ref from use_ref().

    		 None
    key Optional[str]

    Stable identity among siblings.

    		 None

    Type Description

    The preview element.

    Type Description
