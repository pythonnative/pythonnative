    Motion¶

    Worklets, shared values, animations, layout animations, and shared-element transitions (RFC 0009). Interaction logic runs on the UI thread inside the renderer core as worklets, Python functions in a subset the core compiles, verifies, and interprets, so motion keeps up with the finger while the Python thread is busy. The Motion guide explains the model and walks through every piece.

    The everyday names are exported from pythonnative itself: worklet, SharedValue, AnimatedStyle, FrameInfo, the hooks, the with_* animations, Easing, Spring, and the helpers. The layout animation presets, Keyframes, SharedTransition, LayoutAnimationConfig, and WorkletError live in pythonnative.motion:

    import pythonnative as pn
from pythonnative.motion import FadeIn, FadeOut, LinearTransition, SharedTransition

    The components built on Motion, BottomSheet and Swipeable, are documented with the other components.

    Worklets¶

    worklet ¶

    worklet(fn: F) -> F

    Mark fn as a worklet, so callbacks that accept one run it on the UI thread.

    The function is unchanged: calling it from Python runs it as Python. Event props and gesture callbacks run a worklet in the renderer core, on the UI thread, instead of in Python. It's compiled the first time it's installed, and a construct the UI thread can't run raises WorkletError with its location.

    Example 
    @pn.worklet
def drag(event: gestures.GestureEvent) -> None:
    offset.value = event.translation_x

    is_worklet ¶

    is_worklet(value: Any) -> bool

    Whether value was marked with @worklet (or passed as an inline lambda to a worklet API).

    Shared values¶

    SharedValue ¶

    SharedValue(initial: T, *, readonly: bool = False)

    Bases: Generic[T]

    A value the UI thread owns and Python can read, write, and animate.

    Create one with use_shared_value. In a worklet, .value reads and writes the UI thread's copy directly. In Python:

    • Reading .value returns the latest value the UI thread published (it publishes after each frame and event, never waiting for a reader). A read right after a write from Python returns the written value until the UI thread has applied it.
    • Writing .value queues the write behind pending mounts. Writing an animation (value = pn.with_spring(0)) starts it; writing a plain value cancels a running animation.
    • await shared.animate(animation) starts an animation and returns True once it finishes, or False if something interrupted it. Canceling the awaiting task cancels the animation.

    Reading .value during a render doesn't re-render when it changes; drive the view with use_animated_style instead.

    Methods:

    Name Description
    animate

    Run animation on this value and return whether it finished.
    cancel

    Stop a running animation where it is.

    Attributes:

    Name Type Description
    value T

    The latest value: the UI thread's, or a write from Python it hasn't applied yet.

    use_animated_style ¶

    use_animated_style(
    worklet: Callable[[], Style],
) -> AnimatedStyle

    A style the UI thread recomputes whenever a shared value it reads changes.

    Put it in any built-in component's style list, after the static styles it overrides. The worklet runs once when the view mounts, before its first frame is drawn.

    Example 
    moved = pn.use_animated_style(lambda: {"transform": [{"translate_x": offset.value}]})
return pn.View(child, style=[styles.card, moved])

    use_animated_reaction ¶

    use_animated_reaction(
    prepare: Callable[[], T],
    react: Callable[[T, Optional[T]], None],
) -> None

    Run react(current, previous) on the UI thread whenever prepare()'s result changes.

    prepare tracks the shared values it reads. react typically writes another shared value or calls back with run_on_python.

    Example 
    pn.use_animated_reaction(
    lambda: offset.value > threshold,
    lambda past, _: pn.run_on_python(set_past, past),
)

    use_frame_callback ¶

    use_frame_callback(
    worklet: Callable[[FrameInfo], None],
    *,
    active: bool = True
) -> None

    Run a worklet on the UI thread every display frame while active.

    Example 
    def spin(frame: pn.FrameInfo) -> None:
    angle.value = (angle.value + frame.delta_ms * 0.18) % 360

pn.use_frame_callback(pn.worklet(spin), active=playing)

    AnimatedStyle, what use_animated_style returns, is documented with the other style types.

    Animations¶

    Animation descriptors, easing curves, and the helpers worklets share with Python (RFC 0009).

    with_timing, with_spring, with_decay, with_delay, with_sequence, and with_repeat return frozen descriptors. Assign one to a shared value (offset.value = pn.with_spring(0)) in a worklet or in Python, or await it from Python (await offset.animate(...)), and the renderer core runs it on the UI thread. Inside a worklet the same calls build the same descriptors in the core.

    interpolate, interpolate_color, clamp, and snap_point are plain functions here and intrinsics in the core, so a worklet computes the same result in both places.

    with_timing ¶

    with_timing(
    to: T,
    *,
    duration: float = 300,

    to may be a number or a color. on_finish is a worklet that receives whether the animation finished (False when interrupted).

    The return type is to's type so shared.value = with_timing(1) type-checks; the value is a descriptor the core runs.

    with_spring(

    rest_displacement: float = 0.01,

    velocity is in units per second (a gesture's velocity_x carries over directly).     with_delay(
    delay_ms: float,

    reduce_motion: ReduceMotion = "system"

    Start animation after delay_ms milliseconds.

    with_sequence ¶

    with_sequence(*animations: Any) -> Any

    Run animations one after another, each from where the last ended.

    with_repeat ¶

    with_repeat(
    animation: T,
    *,
    times: Optional[int] = None,
    reverse: bool = False,

    Easing¶

    Easing holds the curves with_timing and the layout animation presets accept. Each is an EasingSpec, which crosses to the core as data and evaluates the same way in Python. A curve's name as a string ("ease_out") works wherever a curve does.

    Curve Shape
    Easing.linear t
    Easing.ease, Easing.ease_in bezier(0.42, 0, 1, 1)
    Easing.ease_out bezier(0, 0, 0.58, 1)
    Easing.ease_in_out bezier(0.42, 0, 0.58, 1), the default
    Easing.quad t * t
    Easing.cubic t * t * t
    Easing.bounce Penner's bounce-out
    Easing.bezier(x1, y1, x2, y2) A CSS cubic Bézier; y values may overshoot
    Easing.custom(fn) A progress -> eased Python function, sampled at 64 points the core interpolates 
    offset.value = pn.with_timing(1, easing=pn.Easing.bezier(0.2, 0.8, 0.2, 1.0))

    Helpers¶

    These are plain functions in Python and intrinsics in the core, so a worklet computes the same result in both places.

    interpolate ¶

    interpolate(
    x: float,
    input_range: Sequence[float],
    output_range: Sequence[float],
    extrapolate: Extrapolate = "extend",
) -> float

    Map x from input_range onto output_range piecewise linearly.

    Outside the input range, "extend" continues the nearest segment, "clamp" holds the end value, and "identity" returns x. Pass (left, right) to choose each side separately.

    interpolate_color ¶

    interpolate_color(
    x: float,
    input_range: Sequence[float],
    colors: Sequence[str],
) -> str

    Blend between colors as x moves through input_range (clamped at the ends).

    clamp ¶

    clamp(x: float, lower: float, upper: float) -> float

    x limited to [lower, upper].

    snap_point ¶

    snap_point(
    value: float, velocity: float, points: Sequence[float]
) -> float

    The point a release at value moving at velocity (per second) lands nearest.

    The release is projected a fifth of a second ahead, so a flick carries past the nearest point, the way a sheet or carousel settles.

    run_on_python ¶

    run_on_python(
    callback: Callable[..., Any], *args: Any
) -> None

    Call callback(*args) on the Python thread.

    In a worklet, this queues the call from the UI thread; the callback must be a name the worklet captures. Called from Python, it calls the callback directly.

    Extrapolate module-attribute ¶

    Extrapolate = Union[
    Literal["extend", "clamp", "identity"], Tuple[str, str]
]

    How interpolate behaves outside its input range: one mode, or (left, right).

    Layout animations¶

    Layout animations: views entering, exiting, and moving (RFC 0009).

    Every view-like component takes entering=, exiting=, and layout=:

    • entering runs when the view is created. Inside a subtree created in the same commit, only the outermost entering animation runs, and views created along with a list row don't animate, so scrolling never triggers them.
    • exiting runs when the view is removed. The component unmounts at once; the renderer holds the native view, animates it out, and then destroys it with its subtree. Only the outermost removed view animates.
    • layout animates the view from its old frame to its new one when a commit moves or resizes it.
    from pythonnative.motion import FadeIn, FadeOut, LinearTransition

pn.View(
    *rows,
    entering=FadeIn(duration=200),
    exiting=FadeOut(duration=150),
    layout=LinearTransition(spring=pn.Spring(damping_ratio=0.8, duration=350)),
)

    FlatList and SectionList animate their rows natively with item_entering, item_exiting, and item_layout, which take the presets here (not keyframes or custom worklets).

    Shared-element transitions¶

    Shared-element transitions between stack screens (RFC 0009).

    Give a view on the screen you push from and a view on the screen you push to the same shared_tag. During the push (and the pop back), the platform lifts the destination view into a transition overlay at the source's place on screen, hides the source, and flies the destination to where it belongs while the screens slide, blending corner radius, background color, and opacity. On iOS the back swipe drives the flight interactively.

    # The journal row
pn.Image(photo, shared_tag=f"photo-{entry.id}", style=styles.thumbnail)

# The entry screen
pn.Image(photo, shared_tag=f"photo-{entry.id}", style=styles.hero,
         shared_transition=SharedTransition(spring=pn.Spring(damping_ratio=0.9, duration=450)))

    Release precompilation¶

    Release builds ship without source, so pn build compiles every worklet while staging. These modules are for tooling and contributors; apps don't call them.

    Compile every worklet in a staged tree before release builds drop the sources (RFC 0009).

    Release builds ship sourceless bytecode, so a worklet can't be compiled from its source on the device. Staging runs precompile_tree first: it finds every @worklet function and every inline lambda passed to an API that only accepts worklets, compiles them, and writes pn_worklets.json at the root of the tree, which is on sys.path in the app. At run time a code object is looked up by its file, first line, and name, and a lambda by where its body starts, which both ast and co_positions() report.

    The compiler¶

    Compile worklets: Python functions the renderer core runs on the UI thread (RFC 0009).

    A worklet is ordinary, type-checked Python written in a subset the core can verify and bound. This module parses its source with ast, checks it against the subset, and emits a Program: stack-machine code plus the names it reads from outside (its captures), which pythonnative.motion.worklets resolves each time the worklet is installed.

    The subset:

    • Parameters: positional only, without defaults. An annotation on an event parameter is for the type checker; the core reads the event's fields by name.
    • Literals: int, float, bool, None, str, tuples, lists, and dicts.
    • Operators: arithmetic (+ - * / // % **), unary -, +, and not, comparisons (chained, in, is), and, or, and conditional expressions.
    • Statements: assignment (including augmented and tuple unpacking), if/elif/else, for over range(...) or a sequence, break, continue, return, pass, and expression statements.
    • List and tuple comprehensions over range(...) or a sequence.
    • Calls to other worklets, abs, min, max, round, int, float, bool, len, math functions, and the motion helpers.
    • .value on shared values, .cancel() on a shared value, and fields of event parameters.

    Anything else raises WorkletError with the file, line, and column, and a suggestion.
